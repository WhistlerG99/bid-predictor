Guide

Bayesian Hyperparameter Tuning in the Bid Predictor

This guide explains how the tune_catboost.py utility performs Bayesian hyperparameter optimization for the CatBoost-based bid predictor. It covers the objective function, scoring process, optimization loop, and the configuration files that define the search space.

High-Level Workflow

1. Load Search Space

tune_catboost.py reads a YAML or JSON configuration and converts it into optimization dimensions for CatBoost hyperparameters and feature transformation overrides using build_search_space.

2. Prepare Data

Training features and labels are extracted with prepare_features, mirroring the production data preparation pipeline. Cross-validation folds are generated with StratifiedKFold.

3. Iterate with Bayesian Optimization

A skopt.Optimizer proposes parameter combinations. Each candidate is evaluated via cross-validation and reported back to the optimizer, which refines subsequent suggestions.

Objective Function and Scoring

The optimizer is tasked with maximizing the mean cross-validated score returned by scikit-learn's scoring API. The default scoring metric is roc_auc, but any scorer name accepted by sklearn.metrics.get_scorer can be supplied via the --scoring flag.

For each suggested configuration, the script builds a pipeline with the selected CatBoost parameters and feature overrides. It then calls cross_validate_with_eval, which:

  • Clones the pipeline for each fold.
  • Fits the model with CatBoost evaluation sets for early stopping.
  • Computes the requested score using the appropriate prediction interface.

The fold scores are averaged to produce the objective value. To express a maximization problem to skopt.Optimizer, the script reports the negative mean score when calling optimizer.tell. The best result is tracked along with the standard deviation across folds to quantify variability.

The objective function is effectively: maximize mean_cv_score(params), where mean_cv_score aggregates the selected scorer across stratified folds.

Optimization Loop Details

The optimization loop in tune_catboost.py uses a Gaussian Process surrogate model with Expected Improvement as the acquisition function. Key characteristics include:

Setting Description
base_estimator="GP" Gaussian Process regression models the objective surface.
acq_func="EI" Expected Improvement balances exploration and exploitation.
n_initial_points Latin Hypercube samples warm-start the search with a diverse set of evaluations (up to twice the number of dimensions, capped at 10).
max_combinations Controls the total iterations of Bayesian updates. When omitted, the script defaults to 25 evaluations unless the search space is constant.

Each evaluation records the candidate parameters, mean score, and score standard deviation. At the end of the run the script prints a leaderboard, optionally exports the full history to CSV, and can emit the feature configuration corresponding to the best score.

Search Configuration Files

Search spaces are described with two top-level sections: catboost for estimator parameters and transform for feature-level options. build_search_space converts each entry into an optimization dimension that the Bayesian optimizer can explore.

Default Configuration

catboost:
  iterations: [200, 400]
  depth: [6, 8]
  learning_rate: [0.05, 0.1]
  l2_leaf_reg: [3.0, 5.0]
transform:
  impute_median: {}
  impute_value: {}
  outlier: {}
  bins: {}

If no search file is supplied, this default is used. Each list becomes a continuous or categorical optimization domain, depending on the value types.

Custom Example

catboost:
  iterations: [300, 600, 900]
  depth: [5, 7, 9]
  learning_rate: [0.03, 0.06]
  subsample: [0.6, 0.8, 1.0]
transform:
  impute_median:
    rfm_score: [true, false]
  impute_value:
    user_segment: ["retail", "b2b"]
  outlier:
    spend_ratio: [null, 8.0]
  bins:
    transaction_count: [10, 20, 30]

In this configuration:

  • Boolean and categorical options become Categorical dimensions.
  • Numeric ranges are translated into Integer or Real spaces that allow the optimizer to interpolate between values.
  • Per-feature overrides let you explore different imputation strategies, outlier caps, or binning levels alongside model hyperparameters.

Executing the Tuning Script

Run the tuner from the repository root. Provide a training dataset and optional search configuration: 

python tune_catboost.py \ 
  --train-file data/train.parquet \ 
  --feature-config configs/features.yaml \ 
  --search-config search_configs/catboost.yaml \ 
  --cv-splits 5 \ 
  --scoring roc_auc \ 
  --max-combinations 40

The script prints progress for each evaluation and summarizes the top configurations when it finishes. Use --output-csv to persist the evaluation history and --best-config-out to export the feature metadata for the leading run.

For implementation details, refer to tune_catboost.py and the modules under bid_predictor/tuning/.
